How to label

  • Every bird needs a box. Detector boxes are pre-filled; check them.
  • Click a box (or its row) to select the bird. The yellow box is selected.
  • Click on the image to place a visible eye for the selected bird (order doesn't matter, max 2).
  • H next empty eye slot = hidden (turned away / covered). R = unresolvable (can't see at this size). K = unknown.
  • C toggle "closed" on the selected bird's visible eyes.
  • Z undo last eye on the selected bird. Del delete the selected box.
  • B then drag: draw a new bird box.
  • X no bird in this frame (removes all boxes). E exclude frame (can't judge).
  • Wheel = zoom at cursor. Right-drag or Space+drag = pan. 0 = fit.
  • Tab select next bird.
